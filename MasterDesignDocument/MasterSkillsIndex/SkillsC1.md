# SkillsC1 — Necessary Skills for Ares SpecOps Agentic Lab

**Status.** FROZEN. **Parent:** Master Design Document index.  
**Principle.** Quality over quantity. Necessary over sufficient. Each skill listed is **necessary** — removing any one causes a verification gate (C15) to become unexecutable or a preregistered ablation (C09) to become unrunnable.

---

## Skill Definition Schema

Each skill entry follows:

| Field                          | Description                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| **Skill ID**                   | Unique identifier `SKL-XX`                                                                  |
| **Name**                       | Human-readable name                                                                         |
| **Category**                   | One of 7 top-level skill categories (see README.md in this folder — the skill taxonomy)                              |
| **Necessity Justification**    | Why this skill is necessary (not merely useful) — tied to specific C15 gate or C09 ablation |
| **Broad Definition**           | What the skill encompasses at capability level                                              |
| **Required Tools**             | Tools the skill operator must command                                                       |
| **Required Process/Workflows** | Process/workflow definitions the skill executes or governs                                  |
| **Required Agentic Runbooks**  | Runbooks (C22) the skill must be able to invoke/author                                      |
| **Verification Gate Mapping**  | Which C15 gates this skill directly enables                                                 |
| **Ablation Mapping**           | Which C09 ablations this skill directly enables                                             |

## Necessity Proof: Why These 7 and No Others

| Candidate Skill              | Verdict                       | Reason                                                                                      |
| ---------------------------- | ----------------------------- | ------------------------------------------------------------------------------------------- |
| Frontend/UI Engineering      | **Sufficient, not necessary** | C19 (Frontend) is important but can be staffed by generalist; core runtime (C28–C31) cannot |
| Database Administration      | **Subsumed**                  | Covered by SKL-04 (ledger) + SKL-06 (SQL migrations)                                        |
| DevOps/Cloud Engineering     | **Subsumed**                  | Covered by SKL-03 (wrangler) + SKL-07 (compliance) + SKL-05 (build receipts)                |
| ML Research/Curvature Tuning | **Deferred to P6**            | C06.7 (Self-tuning curvature) is PROPOSED, not required for sprint                          |
| Distributed Systems          | **Deferred to P6**            | C06.10 (Differential Atlas sync) is PROPOSED, not required for sprint                       |
| Prompt Engineering           | **Not a skill**               | Covered by SKL-03 (runtime) + SKL-07 (prompt-injection IFC)                                 |

**Conclusion**: These 7 skills are the **minimal necessary set** to execute all C15 gates and C09 ablations for the 10-day sprint. Each maps to multiple gates/ablations; removing any creates an unexecutable gap.
