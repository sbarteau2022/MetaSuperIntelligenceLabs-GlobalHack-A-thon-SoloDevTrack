## Source and exact ingest contract

The existing `research_library_v1` SpecOps points were produced by
`/tmp/ingest_spec.py`. The ingest path tokenizes the plain chunk text with the
checkpoint tokenizer (`tok.encode(text)`), calls the Qwen3 VL language model's
`model` submodule with that token sequence, takes the last token's first 1024
hidden components, then L2-normalizes those 1024 components. It does not use
the embedding model's separate instruction/pooling wrapper. `text_rank1` is
the recorded pair rotation of rank0, not an independent semantic embedding.

The weights path is a symlink; resolve and pin the target digest before loading.
Config: 28 dense decoder layers, hidden 2048, 16 Q heads, 8 KV heads,
head dimension 128, SiLU gated MLP 6144, interleaved multimodal RoPE,

and biases. The existing native Qwen executor in the separate Rust server
accepts 40-layer Qwen3.5 MoE only; it is not a valid VL encoder.

## Native implementation and promotion gates

Implement a dedicated Rust-owned VL text executor over the existing native
MLX C++ operator bridge; no Python process, prompt wrapper, or JSON model I/O.
JSON remains only for bounded on-disk checkpoint metadata and HTTP Qdrant
transport. Load weights once, tokenize in Rust, run all 28 text layers with
causal attention and exact interleaved RoPE, apply the final RMS norm, slice
and normalize the last hidden state. Refuse missing/wrong checkpoint digests,
empty or over-limit text, nonfinite/zero norm, and encoder version mismatch.
Keep query text caps aligned with the admitted ingest chunk profile and
measure latency before raising caps.

1024 f32 components`, for plain text `hyperbolic memory` (five tokenizer

The native path must then cross-check multiple real stored points

0.000676806, so exact bit parity with stored vectors is currently unproven.

Do not replace BM25 text retrieval until native parity and live retrieval
quality gates pass. The dense lane must use the recorded encoder identity and
return source provenance. PAMI control is a separate later gate: a rotated
duplicate is not evidence of independent rank or multifractal gain.
