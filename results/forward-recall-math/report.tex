\section*{Scope and frozen method}
This is an L0/L1 proof and one isolated live boundary test, not a full model forward pass. The implementation variable is one membership predicate in the harness bridge; the retrieval metric, Surreal data model, model weights, and tensor identity remain fixed. The tests are: one matching recalled address, one two-atom mismatched address, and one mismatched model digest. No speed or quality threshold is claimed.
\section*{Exact join theorem}
Let $N$ be the validated decoded neighborhood, $I$ the requested exact tensor identity, and $P(I)$ the stored K/V page. Exact lookup establishes $P(I)$ belongs to the specified model/session and matches the requested payload digests. It does not establish that $P(I)$ belongs to the selected recall. A necessary condition for a recall-conditioned forward preparation is
\[I.\mathrm{address}\in\{m.\mathrm{address}:m\in N\}.\]
Proof by counterexample: put atoms $A,B$ at distinct valid coordinates. Store a valid exact K/V page at $A$. Query nearest $B$ with $k=1$. The graph read returns $\{B\}$ and exact page lookup at $A$ succeeds, yet the joined result is unrelated. The new predicate rejects this case. This proves address consistency only; it does not prove tensor provenance from the recalled atom's content, useful inference, or full-model parity.
\section*{Prefix identity condition}
For a frozen model roster $M$ containing verified weights and tokenizer, exact token-prefix bytes $x$, and tensor contract $T$, a reusable K/V page requires equality of the model roster digest, prefix digest, positional configuration digest, tensor shape/layout, and page payload digests. If any differ, exact reuse is unsound in general. Even when all match, collision resistance of SHA-256 and correct model execution are assumptions, not mathematical guarantees. The current roster digest includes tokenizer and weight artifact hashes; the prefix digest hashes token IDs. It is a conservative exact-model cache, not cross-model tensor reuse.
\section*{Radix key ambiguity and repair}
The prior cache key hashed raw concatenation of optional parent, token, model, tokenizer, and quantization IDs. For fixed model lane, `(parent=\texttt{Some("a")}, token=\texttt{"b"})` and `(parent=\texttt{None}, token=\texttt{"ab"})` produced the same byte stream before hashing. This is a deterministic encoding collision, independent of SHA-256. The repaired preimage has a version domain, a parent-presence byte, and a little-endian 64-bit length before each present field. Parsing is unique by induction over the five fields, so different field tuples have different preimages. SHA-256 collision resistance remains an assumption. The test also checks model, tokenizer, and quantization lane separation.
\section*{Active-inference objective counterexample}
The proposed AttentionEconomics specification states that maximizing $R=Q/(H+cN)$ also minimizes $F=\mathrm{complexity}(H,N)-\mathrm{accuracy}(Q)$. This does not follow. Under the natural instantiation $C=H+cN>0$, $F=C-Q$, choose actions $A:(Q,C)=(0.9,3)$ and $B:(Q,C)=(0.2,1)$. Then $R_A=0.3>0.2=R_B$ but $F_A=2.1>0.8=F_B$. Both have positive heat, e.g. $c=0.5,N=1,H_A=2.5,H_B=0.5$. Therefore the objectives select opposite actions. The general claim is refuted. A defensible controller must predeclare a quality floor and budget, then minimize measured or predicted cost subject to those constraints; a ratio objective can be tested separately. Landauer's bound is a lower bound on irreversible erasure cost, not proof that measured device heat or this reward produces alignment.
\section*{Existing controller audit}
The current harness `PolicyRanker::rank` sorts by `-pragmatics-0.5 epistemic` and only uses `landauer_cost` for a later probe ratio, so the ranked execution choice is not resource-constrained. In `fep.rs`, complexity/inaccuracy are labeled nats while dissipation is joules, but the default coefficient is dimensionless `1.0`; these terms cannot be added as physical quantities without a declared conversion. Its comment also reverses the beta limit: for `F=accuracyCost+\beta\cdot dissipation`, increasing positive beta penalizes dissipation more, not less. These are code/spec findings, not a measured energy result. A budgeted quality-floor policy is therefore deferred pending a pinned unit convention and calibration.
\section*{Verification and limits}
The exact-integer Rust script \texttt{scripts/verify.rs} checks the explicit counterexample and enumerates all $Q\in\{0.1,\ldots,1\}$, $C\in\{1,\ldots,10\}$ pairs; SHA-256: \texttt{f2bd3feec633be9662996bec9a7c2148019e0a2d04d4214fa7cbd1bef343eed7}. It reported 968 ordering disagreements. The isolated SurrealKV bridge test exercises the address predicate using two real atoms and passed. After the cache-key repair, `cargo test --all-targets`, `cargo clippy --all-targets -- -D warnings`, and `cargo fmt --check` passed; the live bridge test passed separately before that cache-only change. These gates establish boundary and key correctness, not inference or throughput. No independent verifier-agent vote was used because owner instructions forbid spawning agents without explicit approval. The live forward executor and Qwen query encoder remain open in TODO.md.
