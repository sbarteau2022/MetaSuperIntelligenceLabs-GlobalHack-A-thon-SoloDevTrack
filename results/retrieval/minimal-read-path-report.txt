1. What was built (ablation 1 now has its read half)
- retrieve(): reads atom addresses + atoms from an isolated SurrealDB
  (0001 tables only), ranks the H3xT2 neighborhood client-side, and
  returns a receipted RecallBundle (query digest, ranking digest over
  ordered ids/scores/content digests, scanned count, metric).
- Metrics: hyperbolic (M-1 cost form d_H3 + 0.25*d_T2^2, delegated to
  the verified whitehead primitives after fail-closed validation) and
  flat Euclidean control (kept for Queue 2 ablation 3).
- GMRC v1 binary recall-bundle codec for the model-I/O handoff: magic,
  version, workspace, query digest/provenance, metric, members with
  coords/scores/ranks, ranking digest, trailing sha256.
- Fail-closed: budget overrun refuses (never truncates), off-sheet /
  past-sheet / non-finite coords refuse, k=0 and empty provenance
  refuse, quarantined core refuses without the explicit override,
  ranking ties break by atom id (deterministic).
